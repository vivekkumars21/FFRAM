# For Friends resource manager

This repository was created to help my friends and other learners build strong fundamentals in Machine Learning and Deep Learning. It contains well-organized Jupyter notebooks with code implementations, explanations, and practical examples of core concepts.

The notebooks are designed to make it easier to understand algorithms, data preprocessing, model training, evaluation, and deep learning workflows through hands-on practice. This repository will continue to grow as I learn and add more topics.

**What's included:**

* Machine Learning fundamentals
* Deep Learning fundamentals
* Jupyter notebooks with code implementations
* Data preprocessing and feature engineering examples
* Model training and evaluation
* Practical examples and experiments
